Welcome

The Urine Test App provides information about urine test parameters, testing procedures, healthcare stakeholders and medical abbreviations.

This system helps users understand the basic information involved in urine testing.

Urine Test Parameters

Important urine analytes include:

  • Glucose
  • Protein
  • Ketones
  • Blood
  • Bilirubin
  • Nitrite
  • Leukocytes
  • pH
  • Specific Gravity
  • Urobilinogen
Testing Procedure
  1. Collect the urine sample.
  2. Check the sample.
  3. Perform the urine test.
  4. Check the test parameters.
  5. Record the results.
  6. Send the results to the doctor.
Healthcare Stakeholders
  • Doctor
    • Reviews test results
    • Provides medical advice
  • Laboratory Technician
    • Performs urine tests
    • Records laboratory results
  • Patient
    • Provides urine sample
    • Receives test results
  • Hospital Administrator
    • Manages healthcare services
    • Maintains hospital management
Medical Abbreviations
pH
Measures how acidic or alkaline the urine is.
SG
Specific Gravity, which indicates urine concentration.
UTI
Urinary Tract Infection.
RBC
Red Blood Cells.
WBC
White Blood Cells.
UA
Urinalysis, a test used to examine urine.
